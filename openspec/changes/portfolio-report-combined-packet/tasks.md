# Tasks

> **Phase gate:** each numbered group below is a phase. A phase's last task is always to run its
> Cucumber feature and get it green. Do not start the next phase until that happens — if it fails,
> fix the phase you're on rather than moving forward and coming back later.
>
> **Traceability:** every H/E/X row in [design.md](design.md#worked-examples) gets exactly one
> Cucumber scenario with a comment line directly above it naming the ID and the path
> (`# H5 — Happy path: …`). Each feature file header links to `design.md#worked-examples`. Code
> comments name the IDs whose path runs through each service, job and significant branch
> (guard, refusal, skip, fallback), e.g. `# X7 consolidated part fails; X8 nothing generated`.
>
> **Running tests:** always `TEST_ENV_NUMBER=$RANDOM bundle exec cucumber …`; Redis must be up on 6379.
> File paths and method contracts are in [lld.md](lld.md).
