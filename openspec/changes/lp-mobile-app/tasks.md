# Tasks

> **Phase gate:** each numbered group below is a phase. A phase's last task is always to run its
> Cucumber feature (or, for app phases, its Maestro flows) and get it green. Do not start the next
> phase until that happens. If it fails, fix the phase you're on rather than moving forward and
> coming back later.

> **Traceability:** every scenario and Maestro flow carries a comment `# <ID> — <Happy path|Edge
> case|Error case>: <path>` directly above it, and each feature header links to
> [design.md#worked-examples](design.md#worked-examples). Code comments name the IDs whose path
> runs through each service, job, guard and branch (e.g. `# X7 unbound devise-api token refused`).
> Runs always use `TEST_ENV_NUMBER=$RANDOM`, with Redis up on 6379.

> **Approval needed before phase 1 starts:** this change modifies existing code, namely `User`,
> `BaseNotifier`, `NotificationExtensions`, `Users::TwoFactorController` and
> `evergreen/funds/_lp_card` ([design: changes to existing models](design.md#data-model-and-schema-changes)).
