# Tasks

> **Phase gate:** each numbered group below is a phase. A phase's last task is always to run its Cucumber feature and get it green. Do not start the next phase until that happens — if it fails, fix the phase you're on rather than moving forward and coming back later.

> **Conventions for every phase:**
> - Run every Cucumber command with `TEST_ENV_NUMBER=$RANDOM`, with Redis up on 6379.
> - Run `bundle exec rubocop` on the phase's files before its feature task.
> - Comment code with the worked-example IDs it implements, linking `design.md#worked-examples`.
> - Any change to an existing file must match the guarded shape in [lld.md → Existing classes](lld.md#existing-classes-guarded-changes) and design [Backward compatibility](design.md#backward-compatibility).
