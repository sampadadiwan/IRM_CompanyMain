# Tasks

> **Phase gate:** each numbered group below is a phase. A phase's last task is always to run its
> Cucumber feature and get it green. Do not start the next phase until that happens — if it fails,
> fix the phase you're on rather than moving forward and coming back later.

> **References:** [Spec](specs/ui/dashboard-widgets/spec.md) · [Design](design.md) · [LLD](lld.md) · [QA checklist](qa-checklist.md).
> **Run rules:** every cucumber run uses a fresh `TEST_ENV_NUMBER=$RANDOM`; Redis must be up on 6379.
> **Traceability:** every scenario has a comment line directly above it naming its ID and path, for example `# H1 — Happy path: menu lists only Show Menu widgets, in position order`; each feature header links to `design.md#worked-examples`; code comments name the IDs whose path runs through them (for example `# E2 one enabled widget, Show Menu off: no widget links`).
> **Before creating any new `.feature` or step file:** confirm the path does not exist (Write replaces silently).
