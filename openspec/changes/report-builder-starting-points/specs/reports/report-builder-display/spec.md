# Spec Delta

## REMOVED Requirements

### Requirement: Applying a template asks first
**Reason**: Templates no longer apply to an existing report — using a template always creates a new report (report-builder-starting-points, "Create a report from a template"), so there is nothing to replace and nothing to confirm.
**Migration**: Use New report › From a template to create a report from a template; use Duplicate to start from an existing report.
