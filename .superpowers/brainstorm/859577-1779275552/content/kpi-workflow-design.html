💡 Key Improvements Made in This Area

Key Enhancements

  • Unauthenticated Magic Link Support: Integrated Pundit with `@signed_id_user` so portco users can securely view and edit reports without needing a full user account or login session.
  • Friendly Expired/Invalid Link Handling: Replaced generic 500 errors and sign-in redirects with a friendly, unauthenticated-safe error page (returning HTTP status 410 Gone) when a magic link is invalid or expired.
  • Editing Context Preservation: Changed redirects after creation, update, and review actions to point to the Edit page instead of the Show page, keeping users in their active workflow.
  • Portco Pending Dashboard Optimization: Optimized the pending requests dashboard to query directly by the portfolio company's entity, ensuring reliable access without requiring explicit access rights on the fund's KPI reports. Standardized dates to ISO8601 (`YYYY-MM-DD`) format.
  • Clean Layout & Nested Form Fix: Moved the "Mark as Reviewed" button outside the main form block to prevent invalid nested HTML form elements, resolving form submission conflicts.
