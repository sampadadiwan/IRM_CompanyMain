# Release Notes - V9.1.98

## Overview
This release introduces a comprehensive system for viewing and restoring deleted records across multiple modules, along with a new utility for resetting user access rights cache.

## Motivation
The primary motivation was to provide administrators with better tools for data recovery (soft-delete restoration) and to resolve potential access right synchronization issues through a manual cache reset mechanism.

## What Changed
### Core / Infrastructure
- **Soft-Delete Restoration System**:
  - Added `restore_deleted` and `show_deleted` actions to [`ApplicationController`](app/packs/core/base/controllers/application_controller.rb).
  - Created a universal [`deleted_index.html.erb`](app/packs/core/base/views/layouts/deleted_index.html.erb) layout to display and restore soft-deleted records.
  - Enabled restoration for numerous resources including: `QuickLinks`, `Reminders`, `Folders`, `Documents`, `Investors`, `CapitalCalls`, `KPIs`, `Deals`, and more (see [config/routes/](config/routes/) changes).
- **User Access Rights**:
  - Added a "Reset Access Rights Cache" feature to the user show page (visible in debug mode).
  - Implemented [`ResetAccessRightsCacheJob`](app/packs/core/users/jobs/reset_access_rights_cache_job.rb) to handle the reset process in the background.

### Funds
- **Capital Remittances**:
  - Added `payment_notification_sent` toggle to [`CapitalRemittancePayment`](app/packs/funds/capital_remittances/models/capital_remittance_payment.rb) (inferred from form/controller changes) to track and filter notification delivery.
- **Tracking Currency**:
  - Refactored [`TrackingCurrencyJob`](app/packs/funds/funds/jobs/tracking_currency_job.rb) to improve how tracking currency conversions are handled for various fund-related records.

### Startups / Investments
- **Investment Charts**:
  - Refactored [`_charts_content.html.erb`](app/packs/startups/investments/views/investments/_charts_content.html.erb) to use a more dynamic and maintainable approach for rendering various investment-related charts.
- **Security**:
  - Added explicit authorization check for portfolio companies in [`InvestmentsController`](app/packs/startups/investments/controllers/investments_controller.rb).

## Refactoring / Behavior Changes
- The restoration logic in `ApplicationController` automatically handles restoring associated folders (like `document_folder_id` or `data_room_folder_id`) when a record is restored.
- Chart rendering in the investments module is now driven by a configuration array, making it easier to add or toggle charts via parameters.

## Testing
- Added Cucumber feature [`user_access_rights_cache_reset.feature`](features/core/user_access_rights_cache_reset.feature) and corresponding step definitions to verify the cache reset functionality.

## Impact
- **Administrators**: Now have a centralized way to view and recover accidentally deleted data across the platform.
- **Performance**: User access rights reset now runs as a background job, preventing UI timeouts for users with complex permission sets.
- **Security**: Enhanced authorization checks in the investments module.

## Review Focus
- **Restoration Logic**: Inspect `ApplicationController#restore_deleted` for recursive restoration edge cases, especially concerning associated folders.
- **Auth Checks**: Review the new `reset_access_rights_cache?` policy in [`UserPolicy`](app/packs/core/users/policies/user_policy.rb).
