# Release Notes V9.2.08

1. **Overview**: Introduced batch processing, UI enhancements, and scheduled executions for the Portfolio Company Agent.
2. **Motivation**: To allow users to process multiple portfolio companies efficiently, view progress seamlessly, and support automated scheduled executions.
3. **What Changed**:
    - Added `portfolio_agent_runner_controller.js` for handling batch agent execution in the UI.
    - Updated `AgentChartJob`, `SupportAgentsController`, `SupportAgentJob`, and `PortfolioCompanyAgent` to handle `:adhoc_batch`, `:single_company_with_steps`, and `:scheduled` execution modes.
    - Enhanced the `SearchController` spinner UI.
    - Added `PortfolioCompanyChatProvider` to provide portfolio-company-specific context for chat.
    - Added views for enhanced support agent reports (`_support_agent_report_enhanced.html.erb`) and execution history (`_execution_history_tab.html.erb`).
4. **Refactoring / Behavior Changes**:
    - `SupportAgentJob` now uses `execution_mode` to distinguish between batch runs and single company runs with step UI.
    - `AgentChartJob` logic has been updated to handle generating charts silently for scheduled runs.
5. **Testing**: Manual testing of batch runs and single runs via UI is recommended to ensure correct tracking and UI updates.
6. **Impact**: Improves the user experience and efficiency for managing large numbers of portfolio companies.
7. **Review Focus**: Review the asynchronous UI updates via Turbo Streams and ensure background job queuing scales well with batch runs.
8. - Implemented a new Portfolio Company Agent runner controller.
   - Refactored support agent job execution modes.
   - Added enhanced support agent report views.

---

## Business Impact & Updates

- **Bulk Portfolio Analysis**: You can now run the Portfolio Company Agent on multiple companies at once, saving significant time when generating compliance and performance reports.
- **Automated Scheduling**: Support for scheduled background executions has been added. The system can now automatically run routine checks across your portfolio and notify you when ready.
- **Enhanced Chat Capabilities**: The AI assistant can now answer questions specific to your portfolio companies based on the latest compliance and data checks, providing instant insights without having to open individual reports.
- **Improved Tracking**: See real-time progress updates when running reports for a single company, and easily view your team's historical execution logs and detailed report outputs with the new enhanced UI components.
