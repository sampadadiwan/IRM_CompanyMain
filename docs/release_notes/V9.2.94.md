# Release Notes — V9.2.94
**Released: 10 September 2026**

---

## What's New

### Weekly task email — a Friday summary of your team's work
Every Friday, people at your fund who are tagged for Tasks receive one email covering the week: what was completed, what falls due next week, and what is running late. Each person sees the tasks they are allowed to see, so administrators get the whole fund and everyone else gets their own work. Every task in the email links straight to it, and the email is switched off until you turn it on for your fund.

### Conditions precedent and subsequent, pulled from your deal documents
A new agent reads shareholders' and share subscription agreements for a portfolio investment and pulls out the conditions precedent and conditions subsequent, the same way the side letter agent handles investor obligations. Extracted items land in the obligation matrix tagged by legal category, ready for you to approve, reject or edit. You can also add a condition by hand and attach it to the right portfolio investment.

### Choose what each investment opportunity shows to investors
Two new checkboxes on the opportunity form let you hide the Fund Raise Amount, Minimum Ticket Size and Last Date tiles, and hide the Express Interest button and the panel that goes with it. Both are on for every existing opportunity, so nothing changes until you turn them off. This applies to the opportunity detail page only, so listing cards, dashboard widgets and notification emails are unaffected.

### AI answers about capital calls now come with guardrails
When you query capital calls from an AI client, the filters and sort options it can use are now published up front and checked before the query runs. Previously an unsupported filter was quietly ignored and the AI presented the unfiltered result as though it were a filtered answer. You now get a clear message naming the right field instead of a confident but wrong number.

## Improvements

### Watch obligation extraction progress as it happens
The five steps of reading a document now report their own progress, so the panel advances in real time instead of sitting at nothing until the job finishes. If extraction fails you stay on the panel and see why, rather than being sent to an empty matrix.

### Edit an obligation without leaving the matrix
The Edit button now opens the row in place and Save or Cancel puts it straight back. Clicking an obligation title opens the same inline editor. You can also correct the legal category, and portfolio obligations can be edited at any status rather than only while pending.

### Approve, reject and waive obligations without a page reload
Approving or rejecting updates just that row. Obligations that have already created a task now offer Waive instead of Fire, so you cannot create the same task twice, and the Next Due column shows the due date and count of tasks already raised. The Fire button now appears only for obligations that genuinely have no date.

### Filter the obligation matrix by stakeholder
The full obligation matrix now filters by stakeholder in place of the old MFN filter, and the fund filter returns the right rows for portfolio obligations.

### The same filters on the task list and the task board
The task list previously offered only category and due date while the board offered six filters, even though both applied all of them. Both now share one filter bar, so the list gains assignee, stakeholder, contact and tag. The category filter offers the categories actually in use, so your own free-text categories are now filterable.

### Find a stakeholder by typing instead of scrolling a long list
The stakeholder filter on task views is now a search box that looks up names as you type, rather than a dropdown holding every investor at your firm. Pages carrying that filter load noticeably faster at large firms.

### Dates in data grids now match the rest of the page
Dates inside data grids follow the same format as dates rendered everywhere else on the page. Previously grids always showed month-first dates regardless of your language setting, so a day-first date could appear two ways on one screen.

### Text-message sign-in works for phone numbers from any country
Two-factor codes by text used to be sent only to numbers matching the country of your deployment, which locked out anyone holding a mobile from elsewhere. Any valid mobile number can now receive a code. The field is now labelled Mobile Phone.

### Phone numbers are checked when you save them
Saving an unusable mobile number now shows an error on the form. Previously it saved without complaint and then quietly failed to offer text-message sign-in, with nothing on screen explaining why. Existing records are left alone unless you edit the number.

### Clearer role choices on the user form
The user form now shows only the roles you are able to change, and the company administrator role can be granted only by an existing administrator. Other roles a user holds are left untouched, and you can now remove a user's last remaining role.

### Renaming an investor updates the right records, faster
Renaming an investor now refreshes the stored name on account entries for that entity only, instead of reaching across entities. The refresh is also processed in batches on every path, which prevents the database lock errors that could appear on investors with very large numbers of entries.

### Document downloads are more reliable under load
Document generation now keeps a separate working area per job, so several documents being produced at the same time no longer contend with each other.

### New guide for the Remittance Reconciliation Agent
A step-by-step user guide for the Remittance Reconciliation Agent is now available in the documentation.

## What to Do

| If you use...   | Action                              |
|------------------|-------------------------------------|
| Tasks | Turn on the weekly task digest in your fund's settings if you want the Friday summary. It is off by default and sends nothing until switched on. Make sure the people who should receive it are tagged for Tasks. |
| Portfolio investments | No action needed. Upload a shareholders' or share subscription agreement to have conditions precedent and subsequent extracted, then review them in the obligation matrix. |
| Investment opportunities | No action needed. Existing opportunities still show key metrics and Express Interest. Untick the new boxes on the opportunity form to hide either. |
| Obligation matrix | No action needed. Obligations that already raised a task now show Waive rather than Fire. |
| Two-factor sign-in by text | Check that your mobile number is saved correctly. An unusable number is now rejected when you edit it. |
| AI clients connected to CapHive | No action needed. Unsupported capital call filters now return a clear message instead of an unfiltered answer. |
| Data grids | No action needed. Dates now follow your language setting, so the displayed format may change. |
