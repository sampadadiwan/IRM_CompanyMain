# Release Notes — V9.2.92
**Released: 05 September 2026**

---

## What's New

### Capital Remittance Reconciliation Agent — match bank deposits to remittances automatically
Upload a bank statement for a capital call and the Reconciliation Agent reads every deposit, matches it to that call's outstanding remittances by investor and account details, and checks that the money actually came from the investor's own registered bank account. Clear matches are confirmed automatically; everything else is queued for a quick manual review with the reasoning shown alongside it. A statement generator produces reconciliation statements, and the reconciliation panel now links straight through to the related remittance and payment records.

### Allocation Run Checker — an automatic sanity report after every allocation run
Every allocation run now gets a Pass / Warn / Fail report checking that fund totals, folio entries and other figures line up, so problems surface right after the run instead of being found later. Reports can also be generated for past runs.

### Reusable allocation templates
An allocation run's setup can now be saved as a template and reused, so you don't have to rebuild the same setup from scratch each time.

### Each deal gets its own dedicated email address
Deals now automatically get their own unique email address for incoming documents and updates, replacing the old shared-address setup, so emailed documents are matched to the right deal more reliably.

### Unapprove a capital call
An approved capital call can now be reverted back to unapproved if it was approved by mistake or needs changes, with clear warnings about what unapproving affects.

### Approving a capital call no longer automatically emails investors
Approving a capital call and notifying investors are now two separate steps. Approve simply approves; a new "Send Notification" button sends the email when you're ready, and it won't notify the same investor twice.

---

## Improvements

### Capital call notices no longer show "access denied" for some investors
Two notice templates with the same name could cause the generated document to be deleted and regenerated in a loop, which sometimes left investors looking at a broken link. Duplicate template names are no longer allowed, and existing data has been cleaned up.

### Verify is disabled until a payment has actually been received
The Verify button on a capital call remittance could previously be clicked even when nothing had been paid, showing a confusing warning. It's now greyed out until a payment is recorded.

### Fixed a scenario where some capital calls could skip approval
Certain fund unit/ratio call scenarios could bypass the capital call approval step entirely. Approval is now always required before a call can proceed.

### Audit trail no longer cluttered by fee recalculations
Automatic fee recalculations on capital distribution payments were showing up as noisy entries in the audit trail. They're now excluded, so the trail reflects real changes only.

### Region-aware defaults and cleaner forms
The default phone country code now follows your region automatically, the Department field is hidden on user forms for investors, and the two-factor setup description now mentions SMS as an available verification method.

### Steadier real-time page updates
Fixed an issue where some pages weren't reliably notified of background changes, which could leave a screen looking out of date until it was refreshed.

### More reliable allocation runs on large funds
Fixed a memory issue in the allocation engine that could affect very large allocation runs.

## What to Do

| If you use...   | Action                              |
|------------------|-------------------------------------|
| Capital calls | No action needed. After approving a call, use the new "Send Notification" button when you're ready to email investors. Use "Unapprove" if a call needs to be reopened. |
| Capital call remittances | No action needed. Run reconciliation from the call page by uploading a bank statement. |
| Allocation runs | No action needed. Check the Pass/Warn/Fail report after each run, and save a run's setup as a template if you'll reuse it. |
| Deals | No action needed. Each deal's dedicated email address is generated automatically. |
| Investor and user forms | No action needed — irrelevant fields are now hidden automatically. |
| Audit trail | No action needed. Fee recalculation entries no longer appear. |
