# Release Notes — V9.2.47
**Released: 22 May 2026**

---

## What's New

### KPI Review — Approve and Mark as Reviewed in One Step

Fund admins can now approve all KPIs and mark a report as reviewed in a single action, directly from the report detail page. The **Approve All KPIs & Mark as Reviewed** button appears on submitted reports and replaces the previous two-step process where approving KPIs and changing status required separate actions.

This ensures no report can be closed out with unapproved KPI data still inside it — the two steps now happen atomically.

---

## Improvements

### KPI XLSX Upload — Submit Guard Now Works Reliably

When a portfolio company uploads a KPI workbook with structural errors (such as missing date column headers), the **Save Draft** and **Submit Report** buttons are now correctly disabled until the file is fixed. A browser compatibility issue was causing the guard to fail silently — portco users may have been able to submit broken files without seeing an error.

### KPI Dates — Clearer Errors for Unreadable Dates

Date values in KPI reports are now parsed with consistent locale handling. If a date cannot be read, the error message is more specific about what went wrong.

### AI Assistant Queries — More Accurate Fund Data Responses

The AI assistant integration (MCP) now receives better guidance when querying fund data, including sort and limit hints and workflow navigation cues. Queries about funds, capital, and portfolio companies should return more relevant, better-ordered results.
