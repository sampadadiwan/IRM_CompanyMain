# Release Notes — V9.2.56

**Released: 10 June 2026**

---

## What's New

### Ratio Formula Import — Load formulas from a spreadsheet

You can now upload a spreadsheet to create or update ratio formulas for a fund in bulk. An Import button appears on the Ratio Formulas page; a sample file is available to download so your team can see the expected format. Duplicate entries are detected automatically and handled without creating conflicting records.

---

## Improvements

### Investor-level ratios on documents — Calculations now reflect each KYC record

When per-investor document generation is enabled for a fund, ratios used in capital call notices, distribution payment notices, and remittance notices are now calculated at the individual investor KYC level rather than the fund level. This means the figures shown to each investor accurately reflect their own position and allocations rather than a fund-wide aggregate.

### Faster loading on large funds — Improved query performance for account entries

A database index has been added to speed up queries that look up account entries by entity. Funds with large transaction histories will notice faster page loads and report generation in areas that draw on account entry data.
