# Release Notes — V9.2.84
**Released: 6 August 2026**

---

## Improvements

### Deal task counts are now more accurate
The Weekly Summary for deals could miscount tasks that were due further out than a few days, sometimes leaving them out of every bucket entirely. Task counts are now split clearly into overdue, due within 7 days, pending (everything else not yet due), and completed — so the numbers you see always add up.

### Setting up a new Deal Agent no longer shows an error
Opening the setup form for a brand-new Deal Management Agent (before it had been saved) could trigger a page error. The form now loads cleanly every time, whether the agent is new or already saved.
