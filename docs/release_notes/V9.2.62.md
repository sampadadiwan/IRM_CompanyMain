# Release Notes — V9.2.62

**Released: 21 June 2026**

---

## What's New

### Agent run preview — see what an agent will do before it runs

When you click "Run Now" on any AI support agent, a confirmation modal now appears showing a plain-English description of exactly what the agent will analyse and what output it will produce. You can review the scope before confirming, so there are no surprises about what was processed or emailed.

### Deal scoring now uses a structured rubric with a full report view

The Deal Management Agent now evaluates each investor across four weighted dimensions — financial capacity, strategic fit, relationship strength, and commitment readiness — to produce a numeric score and a written assessment for every deal. Results are displayed in a detailed report view alongside the rest of your deal pipeline. You can also upload a custom scoring document to override the default rubric with deal-specific criteria.

### Portfolio report templates — upload your own style guide

When configuring a portfolio report template, you can now attach a brand or style document. The agent uses it to match the formatting, tone, and visual conventions of your existing investor materials, so generated reports feel consistent with the rest of your communications.

### Configure AI model keys directly in the app

Administrators can now set and manage LLM API keys (OpenAI, Anthropic, and others) from a dedicated settings screen inside the app. You can add a key, clear an existing key, or choose which model the app uses by default — no server access required.

### Support Agents user guide now available in-app

A new help section covers how to configure and run support agents, including what each agent monitors and how to interpret its output. A link to the guide appears on the support agents index page.

---

## Improvements

### E-sign Monitor now catches failed signatures, not just pending ones

The E-sign Monitor agent previously only flagged documents where a signature was still outstanding. It now also surfaces documents where an e-sign attempt has outright failed, so your team is alerted before the deadline rather than discovering the failure too late.

### Cash flow report email redesigned with clearer status and action cues

The cash flow report email now opens with an overall status banner (All Clear / Monitor / Action Required) and shows each fund with a colour-coded badge — Surplus, Watch, Shortfall, or Blocked. Funds requiring attention are grouped at the top with explicit next-step guidance, making it faster to identify which funds need action on a given run.

### One-click provisioning for the full agent library

Administrators now have a "Setup All Agents" action on the support agents page. It provisions every available agent for your entity in a single step, filling in defaults for any agents that are missing while leaving your existing configuration untouched.
