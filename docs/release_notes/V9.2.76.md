# Release Notes — V9.2.76
**Released: 16 July 2026**

---

## What's New

### Choose which deals and steps your weekly deal summary tracks
The weekly deal summary now has a configuration panel where you pick a specific deal and tick exactly which step transitions you want the summary to watch. This lets you tailor each summary to the pipeline stages that matter most to your team, instead of tracking everything.

### Income-after-expenses figure added to Distribution templates
Fund Term Distribution templates now include an income-after-expenses figure (income with expenses removed) for LPs, GPs, individual investors, and KYC groups, across prior, current, and combined periods, with percentage breakdowns. It sits alongside the existing Total Income and Compensation figure so you can compare income before and after expenses at a glance.

---

## Improvements

### Stagnant deals are now judged against each step's own time limit
An investor is flagged as stagnant based on the time limit set for the pipeline step they are currently on, rather than one fixed number of days applied to every step. This gives a more accurate picture of which deals have genuinely stalled.

### Weekly summary stagnation and task views are easier to read
Stagnant deals now appear as a table showing the investor, their current step and its limit, and how long they have been inactive. Task lists use clear, consistent columns — Details, For, Assigned to, Due, Completed, and Category — matching the deal tasks page.

### Weekly summary now shows names and clean task titles
Step transition details display the investor's name instead of an ID number, task titles show as clean text with formatting removed, and the "View all overdue" link now takes you straight to the correct task list. A misleading label under the stagnation card has also been removed.

### More accurate distribution payment amounts
The payable amount shown in a folio's own currency now calculates correctly, and when several account entries share the same date the most recent one is now used. This keeps distribution payment figures consistent.
