# Release Notes — V9.2.58

**Released: 15 June 2026**

---

## What's New

### Investor Portal — Tighter access controls across all views

Investors who log into the portal now have a more focused, read-only experience. Action buttons such as upload, edit, and delete — as well as bulk download options — are hidden across document lists, capital commitments, distributions, remittances, fund ratios, and portfolio investment views. Only your internal team sees these controls.

---

## Improvements

### Investor Portal — Quick Links section no longer shown to investors

The Quick Links sidebar section is now hidden when an investor is logged in. Investors see only the navigation relevant to their own holdings, reducing confusion and keeping the interface clean.

### Investor Detail Page — Last Interaction date removed

The Last Interaction date field has been removed from the investor detail view. This was an internal operations metric that added clutter without being useful to investors viewing their own profile.

---

## What to Do

| If you use...                          | Action                                                                                   |
|----------------------------------------|------------------------------------------------------------------------------------------|
| Investor portal access                 | No action needed. Investors will automatically see the restricted interface on next login.|
| Internal document and portfolio views  | No action needed. Your team's controls are unchanged.                                    |
