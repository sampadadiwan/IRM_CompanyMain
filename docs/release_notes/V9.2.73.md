# Release Notes — V9.2.73
**Released: 12 July 2026**

---

## What's New

### Weekly deal summaries, delivered automatically
Deal management now includes a Weekly Summary view showing pipeline progress, stagnant deals, task completion, and charts at a glance, plus an optional AI-written insight. The same summary can also be emailed to you on a schedule, so you don't have to open the app to get a pulse check on your deals.

### Require an attachment before a notification can send
Custom notifications can now be marked as requiring an attachment. If the attachment is missing when it's time to send, the notification is skipped instead of going out incomplete, and admins get an emailed report listing what was skipped and why.

### Onboarding and KPI-review workflows now available for investors and portfolio companies
You can now set up a workflow template that automatically launches when a new investor is added (for onboarding) or every time a portfolio company's KPI report is uploaded (for review). Previously, workflow templates only covered folders, KYC, capital commitments, capital calls, and approvals.

### Connect Claude.ai to CapHive with just a link
Fund managers can now connect Claude.ai to CapHive by pasting a single connection URL and logging in — no more waiting on an admin to manually create credentials and share a Client ID and Secret.

### Ratio formulas support readable labels and portfolio-level exclusions
Ratio formulas can now be created and identified using plain-language labels instead of only internal codes, and can be scoped with a parent/entry type. A new option lets a ratio formula skip portfolio fair market value where that's not relevant to the calculation.

---

## Improvements

### Accessibility improvements across the platform
Progress bars, buttons, data tables, pagination, and dropdown menus now carry proper labels and descriptions for screen readers, and keyboard navigation has been improved throughout.

### Deal table is easier to work with, with more configurable columns
The deals list table has been resized for better readability. Deal status can now be configured as a custom field, and you can add "Deal Investor Status" and "Enable Notifications" as standard columns on the deal table.

### WhatsApp notifications no longer silently send your email text instead
If you leave the WhatsApp message blank on a custom notification, WhatsApp delivery is now skipped entirely rather than falling back to sending the email's text. The setup form now also tells you plainly that a blank WhatsApp message means nothing will be sent over WhatsApp.

### Platform-wide security hardening
A broad security review resulted in tightened protections across login links, support access, rate limiting on failed logins, and stricter separation between different organizations' data — reducing the risk of unauthorized access or cross-tenant data exposure.
