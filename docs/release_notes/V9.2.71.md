# Release Notes — V9.2.71
**Released: 5 July 2026**

---

## What's New

### Custom notifications — attach documents by pattern, not just exact name
When setting up a custom fund notification, the **Attachment Names** field now supports wildcards. Add an asterisk (`*`) anywhere in a name — e.g. `SOA_*_2026` — to automatically pick up every commitment document that follows that pattern, instead of typing an exact name for each variation. A new **Only Attach the Latest Match** option lets you choose whether to send just the newest matching document or every one that matches.

### Easier switching between GP entities from the LP dashboard
Investors who have access to more than one GP entity can now switch between them directly from a dropdown in the dashboard top bar, instead of navigating away to change entities.

### Send one email per investor instead of one per commitment
Custom fund notifications can now be sent per investor KYC record instead of per commitment. Select **Adhoc Kyc Notification** from the **For Notification** dropdown when a document or update — a PAN card, a bank form, a compliance update — belongs to the investor rather than to any one commitment. An investor with several commitments in the same fund now gets a single combined email instead of a separate one for each commitment.

### Workflows can now lock buttons until a review is complete
Workflow templates can name specific buttons — such as Approve on a capital call or Verify on a KYC record — to grey out while that object's workflow is running or has failed. This stops an action from being taken before its required review finishes. Workflow templates can also now be applied to capital calls, in addition to folders, KYC records, and commitments.

---

## Improvements

### Data Room link on the dashboard is more reliable
The Data Room card on the dashboard now only appears when a Data Room actually exists for that entity, and clicking it takes you straight to its contents instead of a general listing page.

### Workflow templates now show their running instances in one place
Opening a workflow template's detail page now includes an **Instances** tab alongside Auto Assignment Rules, so you can see every workflow currently running from that template without leaving the page.

### Date fields no longer pop open the calendar unexpectedly
Clicking into a date field to type a value no longer triggers the calendar picker to open on top of it, making manual date entry smoother.

### Document names with commas can now be used in Attachment Names
If a document's name itself contains a comma — for example a date range like `01 July,2025 to 31 December,2025` — wrap that name in double quotes in the **Attachment Names** field so it's treated as one entry instead of being split apart.

### Deal activity template imports now catch missing columns before you save
If an uploaded deal activity template XLSX is missing a required column, the Save button is now disabled and a clear error points out the problem right away, instead of letting the import fail after the fact.

### Viewing a workflow from the instances list now opens the right page
Clicking **View** on the workflow instances list now reliably opens the full workflow instance page, fixing a case where it could land on a blank page instead.

### Smoother import upload experience for XLSX files
The XLSX import upload page has a cleaner layout, guards against accidentally submitting twice, and gives clearer feedback when a sheet's headers don't match what's expected.

### Granting access to large folder trees is faster
Applying access rights to a folder with many nested subfolders no longer triggers redundant background processing for each subfolder, speeding up how quickly access changes take effect.

### Friendlier error pages
The pages shown when something goes wrong (404 and 500 errors) have been redesigned with clearer messaging and a more polished look.
