# Release Notes — V9.2.59

**Released: 16 June 2026**

---

## What's New

### "Investor" is now "Stakeholder" throughout the app

We've renamed "Investor" to "Stakeholder" across forms, buttons, and confirmation messages — when you create, update, merge, or delete a record, you'll now see "Stakeholder" in the notice rather than "Investor". This better reflects that these records can represent investors, portfolio companies, and other parties you work with. Helper text has also been added under each field on the stakeholder form to make it clearer what to enter.

### Save KYC forms in progress, finish them later

Your team can now save a stakeholder's KYC record without filling in every required field or uploading every document first. This makes it easier to capture what you have on hand and come back to complete the rest later, instead of being blocked until the full form is ready.

### Invitation emails now mention the right fund by name

When a stakeholder is invited to the portal, their welcome email subject now includes the specific fund they're being invited by (e.g. "Welcome to CapHive (Acme Capital)"), instead of a generic message. This makes it immediately clear which fund the invitation is from.

---

## Improvements

### Clearer highlighting for missing required fields

Custom fields that are left blank now show the same red highlight and inline message used elsewhere in the app, instead of a plain browser pop-up. Errors clear automatically as soon as you start fixing the field.

### Fewer duplicate error messages when adding a stakeholder

When a stakeholder's name or email already exists, you'll now see one clear message instead of multiple overlapping "duplicate" errors for the same problem.

### Stakeholder names are no longer cut off unexpectedly

First and last names on stakeholder access records previously had a strict length limit that could cause errors or silent truncation for longer names. This limit has been removed.

### Investor portal — additional views and actions restricted

Investors logged into the portal will no longer see the Actions column on data grids, the "Pending KYC Requests" and "Analytics" buttons on the KYC list, the "Run Fund Stats Agent" button, or the Units tab on capital remittance details (when the fund doesn't show units). Portfolio reports are also now scoped to the investor's own entity.
