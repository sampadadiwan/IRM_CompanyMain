# Release Notes — V9.2.80
**Released: 28 July 2026**

---

## What's New

### Portfolio reports — generate documents for many companies at once
You can now generate portfolio report documents in bulk across your portfolio companies, using a template you pick at generation time. Each company's latest KPI extracts, fund-level figures, and most recent portfolio investment details are pulled into the document automatically, and extracts are ordered newest first. Yearly numbers are computed from quarterly KPIs so annual figures stay consistent, and clearer notifications tell you which companies were included and which were skipped for missing data.

### Smarter KPI workbook uploads — headers, budgets, and sub-line items
Uploading KPI workbooks now handles far more real-world Excel layouts. Column headers with dates like "Apr'25" or "2022-04-01" are detected correctly, and Actual vs Budget columns are recognised and kept as separate reports so same-period figures never overwrite each other. Indented or column-based sub-line items (for example "Net Sales — Enterprise" under "Net Sales") are picked up automatically and shown grouped under their parent KPI in the grid, with subtotal rows skipped so nothing is double-counted. Re-uploading the same workbook updates values in place instead of creating duplicates.

### Manually override AML status on investor KYC
Compliance teams can now manually override an investor's AML status when a screening result needs human judgement. The override requires a reason, shows a tooltip explaining why the status was set manually, and every override is recorded in the audit trail.

### Bulk verification of capital call remittances
Instead of verifying remittances one by one, you can now select all unverified remittances on a capital call and verify them in a single step. Remittances with duplicate folios are reported as failures rather than silently skipped, and each verification is logged for traceability.

### Account entry formulas can now generate multiple entries at once
Fund formulas now support generating several related account entries from a single formula, with automatic entry naming and validation. This reduces the number of formulas you need to maintain for fee and allocation structures that produce more than one entry per run.

---

## Improvements

### Bulk actions for fund ratios and fund units
Fund Ratios and Fund Units lists now support bulk actions, including bulk delete for fund units, with every create, update, and delete recorded in the audit trail.

### Capital commitment imports now support feeder funds
You can import capital commitments that route through feeder funds, with validations to catch incorrect fund pairings during the import.

### Distribution exports now show tracking currency fees
Capital distribution payment exports include new tracking currency columns, including fee amounts, so cross-currency distributions are easier to reconcile.

### Safer imports with clearer errors
Portfolio investment imports now stop at the first error instead of partially importing, remittance payment imports require a Payment Date, and formula syntax errors are caught with clearer messages before they cause problems downstream. Document merge errors also report exactly which merge field failed.

### Advisor access rights are clearer and better controlled
Investor access screens now display an advisor's access rights, and users with the Investor Advisor role can no longer create investor access entries they shouldn't.

### Tidier screens and small fixes
The delete button for account entries no longer appears on the import results page (deleting from there could remove entries beyond the import). The Edit button is hidden for completed KYC records on the investor page. Folder path updates after renaming now apply immediately instead of after a 5-minute delay. PDF downloads keep their proper file names, and number and money fields in custom forms display with correct formatting.

## What to Do

| If you use...                          | Action                                                                                      |
|----------------------------------------|---------------------------------------------------------------------------------------------|
| Portfolio reports                      | Pick a template and use the new bulk generate option from the portfolio companies page.      |
| KPI workbook uploads                   | No action needed. Re-upload any workbook that previously imported with missing columns or line items. |
| Investor KYC / AML screening           | Use the new override option on the KYC page when a screening result needs manual review.     |
| Capital call remittances               | Use the bulk verify option on the capital call page to verify all pending remittances at once. |
| Capital commitment imports             | You can now include feeder fund commitments in your import files.                            |
| Everything else                        | No action needed. Fixes and improvements apply automatically.                                |
