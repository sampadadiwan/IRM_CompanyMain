# Release Notes — V9.2.46
**Released: 21 May 2026**

---

## What's New

### Portfolio Company KPI Reporting — Full Workflow

Portfolio companies that submit KPIs through the self-service link now have a proper end-to-end workflow, replacing the previous single-step submission.

**For portfolio companies:**
- **Save Draft** lets a portco user save their progress and come back later without locking the report.
- **Submit Report** formally sends the report to the fund team and locks it from further edits.
- A status badge on the form shows exactly where the report stands: *Created → Link Sent → Draft Saved → Submitted → Reviewed*.
- The reminder email now shows the link expiry date (15 days) so portco contacts know their deadline.
- If a magic link has expired, the user sees a clear error message instead of a crash page.

**For fund teams:**
- When a portfolio company submits, the fund team receives an email notification so nothing falls through the cracks.
- Bulk reminder sends and periodic reminders automatically skip portfolio companies that have already submitted — they will not receive repeat emails.
- A **Mark as Reviewed** button lets fund admins close out a report once reviewed, advancing it to *Reviewed* status.
- A **Portco Pending** dashboard shows all outstanding KPI requests at a glance.

**Designated KPI contact:**
Tag a portfolio company user with the **Kpi** tag to make them the sole recipient of KPI reminder emails. If no one is tagged, all approved portco users receive the reminder as before.

---

### Documents — "As Of" Date

Every document now has an optional **As Of Date** — the business date the document applies to, separate from when it was uploaded.

- The date column in the document list shows the As Of Date when one is set, making it easy to identify "Q1 2025 Investor Statement" vs "Q4 2024 Investor Statement" at a glance.
- When uploading a document manually, you can set the As Of Date in the upload form.
- System-generated documents (capital call notices, distribution notices, investor statements, fund reports, portfolio reports) have their As Of Date set automatically.

| Document | As Of Date Set To |
|---|---|
| Capital Call Notice | Date of the capital call |
| Distribution Notice | Date of the distribution payment |
| Investor Statement | End date of the reporting period |
| Fund Report | End date of the reporting period |
| Portfolio Report | End date of the reporting period |

Investors see the same meaningful dates in their document list, replacing the raw upload timestamps they saw before.

---

### Fund Ratio Run Templates

A new **Fund Ratio Run Templates** section lets teams pre-configure and reuse fund ratio calculation runs without setting up parameters from scratch each time.

- Create a template with a fund (or group of funds by tag), scenario type, and preferred settings.
- Trigger a single template or **run all templates at once** with a single click.
- View the history of past runs and their results from the template page.
- Validation rules now check templates before a run starts and will flag issues upfront.

This is especially useful for teams that run the same ratio calculations each quarter across multiple funds.

---

### Fund Unit Transfers — Currency Date Fix

When a fund unit transfer involves commitments in different currencies, the exchange rate is now looked up against the **original commitment date** rather than the transfer date. This ensures the converted amounts are accurate and consistent with the original commitment records.

---

### LP Commentary on Funds

A new **LP Commentary** text field is available on the fund setup form. Use it to record notes or commentary intended for LP reporting.

---

## Improvements

- **Validation Rules — Fund Ratio Run Templates:** Validation rules now cover Fund Ratio Run Templates, flagging configuration issues before a run is triggered.
- **Scoring Reports:** The AI scoring report detail view has a cleaner, more readable layout.
- **Validation Rule page:** The Validation Rules index page now shows a link to the user guide directly from the page header.

## What to Do

| If you use... | Action |
|---|---|
| Portfolio company KPI reporting | Remind portco contacts to use **Submit Report** (not just save) when they're done. Designate a KPI contact by adding the **Kpi** tag to their user. |

| Fund Ratio Runs | Explore the new **Fund Ratio Run Templates** section to set up reusable configurations. |
