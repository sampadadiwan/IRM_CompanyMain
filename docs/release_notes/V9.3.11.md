# Release Notes — V9.3.11
**Released: 26 October 2026**

---

## What's New

### Portfolio reports — fund money, cost and FMV figures in your templates
Consolidated reports now show, for each company's fund line, the fund's committed, called, collected and distributed amounts as of the report end date. They also show the cost of the remaining holding, cost invested and exited in the period, and FMV at the prior period and financial year start with the change in each. Fund totals add collected and uncollected amounts and percentages, number of companies, summed cost and FMV, and the fund's own IRR, MOIC, TVPI, DPI and RVPI.

### Per-company reports — sold amount, remaining cost and budget variance
Each fund in a company report now shows the amount sold and the cost of what remains. KPI rows also give the percentage difference between actual and budget, so you can show variance without calculating it in the template.

### Run the CP/CS agent from a portfolio investment or its documents
You can now start the CP/CS agent from a portfolio investment page, or from a single document in its documents folder. For a single run you can enter an estimated closing date, and document tags can be separated by commas.

### Run the side letter agent from a capital commitment
The capital commitment page has a **Run SLO Agent** button. After a single run you land on the obligation matrix filtered to that stakeholder. After a batch run you land on the agent's Obligations tab.

### Obligation matrix — one view for conditions and side letters
The obligation matrix now covers condition precedent, condition subsequent and side letter obligations in one place. You can filter by legal category, and the stakeholder list follows the category you pick: companies for conditions, LPs for side letters. The matrix can be sorted by any column, and each row shows an icon for recurring, one-time or event-driven obligations. From the agent tabs, **Open Full Matrix** opens it already scoped to what you were looking at.

---

## Improvements

### Portfolio obligations open on their full page
Clicking a portfolio obligation now opens its page with Tasks, Fulfillment History and Alerts, instead of an inline edit.

### Cleaner obligation edit form
The MFN option and the side letter category are hidden when you edit a condition precedent or subsequent obligation, because they don't apply.

### Clearer breadcrumb on the obligation matrix
The breadcrumb now reads "Obligation Matrix" instead of linking to Side Letters, and keeps your filter when you click it.

### Progress panels sit above details
On portfolio investment and capital commitment pages, agent progress now appears above the details, and no longer shows twice after you navigate back.

---

## Bug Fixes

### CP/CS agent no longer fails when run for several targets
Running the CP/CS agent across more than one company or investment could stop with an error. It now runs for each target.

### Obligation edit no longer errors when you change the legal category
Saving an obligation after changing its legal category could fail with an error. It now saves.

### Obligation matrix no longer errors on empty results or legal category filter
The matrix could show an error when a search returned nothing, and the legal category filter did not apply correctly. Both now work.

### Blank start date is rejected on consolidated reports
A consolidated report with no start date now stops with a clear error instead of producing wrong figures.
