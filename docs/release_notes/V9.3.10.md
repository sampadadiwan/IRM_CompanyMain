# Release Notes — V9.3.10
**Released: 25 October 2026**

---

## Improvements

### No more blank pages in combined portfolio reports
When a combined portfolio report joined several templates, a part that filled its last page completely could leave a blank page before the next part. Each part now starts cleanly on a new page, so the combined document has no stray blank pages.

---

## What to Do

| If you use...                | Action                                                                                  |
|------------------------------|-----------------------------------------------------------------------------------------|
| Combined portfolio reports   | Regenerate any combined report that has a blank page between parts. No other action needed. |
| Everything else              | No action needed.                                                                       |
