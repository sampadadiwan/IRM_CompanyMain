# Release Notes — V9.3.09
**Released: 24 October 2026**

---

## What's New

### Combined portfolio report — one document from several templates
When you generate portfolio reports for several companies, you can now line up report and template rows in the order you want and get a single combined document. The pieces are joined in that order, and the file is named after the first row's template. Different templates join cleanly, and the file is saved under Portfolio Reports / Generated Portfolio Reports.

### Consolidated reports — one cover or summary for all companies
Mark a report as **Consolidated** and its template is produced once for all the companies you select, instead of once per company. Use it for cover pages, summaries and totals. Your template can loop through companies, then their funds, then each fund's ratios, and each fund shows its name, currency, FMV, cost of investment, IRR and MOIC. Fund totals are also available for a Grand Total row.

### Report extracts — built from notes and KPIs when there are no documents
If a company has no documents for the period, its extract is now built from your notes and the approved KPIs of the company's latest KPI report in that period. You see a warning when this happens. Bulk extract runs show that warning once at the end, not once per company.

---

## Improvements

### Sections are optional on portfolio reports
A blank section row is ignored, and a report with a template counts as ready even without sections. Extracts are skipped for reports that have no sections.

### Company step is clearer when generating reports
**Next** stays disabled until you choose a company, and **Preview** tells you when no company matches.

### Company admins can delete a report extract
If an extract is wrong or no longer needed, company admins can now remove it.

### Dashboard widget shows the latest extract with data
The portfolio report widget skips blank extracts and shows the most recent one that has content, even when many blank ones came after it.

### Report extracts only show your own entity's data
Extract lookups are now limited to your entity.

### Note tag filtering fixed in extracts
Extracts built from notes now pick up the notes with the right tags.

## What to Do

| If you use...                  | Action                                                                                          |
|--------------------------------|-------------------------------------------------------------------------------------------------|
| Consolidated or combined reports | Create a Consolidated report with a cover or summary template if you want one document for all companies. |
| Portfolio report extracts      | Check extracts built from notes and KPIs, as they can differ from document-based ones.           |
| Everything else                | No action needed.                                                                               |
