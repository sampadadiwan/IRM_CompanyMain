# Release Notes — V9.2.83
**Released: 6 August 2026**

---

## What's New

### Run Validation — check just the companies you choose
The Portfolio Company Dashboard's Run Validation action can now be scoped instead of always running against every portfolio company. Choose "All portfolio companies" (the previous default), or narrow it to specific companies, a tag, or a sector — the confirmation dialog tells you exactly what's about to run before you commit.

---

## Improvements

### Document type columns now show correctly
The Portfolio Company Dashboard was looking up the wrong internal record when building its document type columns, so some funds saw the columns missing entirely; fields without a display name also produced blank headers. Both are fixed — document types now load correctly, and any field without a label shows a readable fallback name instead.

### Deal agent controls are cleaner and better placed
The Weekly Summary button has moved from an individual deal's tab to the top of the deals list, where it applies to the whole list. Run Now is now hidden for chat-only agents where it never did anything, and an unused "Enable on Demand Run" checkbox has been removed from the agent setup form.

### AML report alerts say what actually happened
Success and failure notifications for AML screening referred to "downloading" the report — an internal step rather than what you experienced. They now say "generated," matching what's actually happening at that point.

### Agent failure and partial-success emails now show what went wrong
These emails previously gave only a pass/fail count with no detail. They now list which records failed and why, right in the email, and correctly describe manually triggered runs instead of labeling every run "scheduled."

### KYC expiry reminders now arrive once per milestone, not once per day
Expiry alerts previously could be re-sent every time the check ran. You now get one reminder per milestone — 60, 30 and 15 days out, plus one when a KYC actually expires — instead of a repeat email each day. Alerts also distinguish "expiring soon" from "already expired," and a blank reminder-threshold setting now safely falls back to the default schedule instead of silently turning off all warnings.

### Document generation is more memory-efficient for large funds
Generating reports that include account entry breakdowns could load far more data into memory than needed for funds with large ledgers, risking slow or failed generation. This has been optimized so document generation stays lean regardless of fund size.
