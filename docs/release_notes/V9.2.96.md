# Release Notes — V9.2.96
**Released: 19 September 2026**

---

## What's New

### Pre-run and post-run checks for allocation runs
A fund can now carry its own checks alongside its allocation formulas. A pre-run check runs before the allocation deletes or computes anything, and a post-run check runs after every formula has finished. Each check passes, warns or fails without creating account entries; any failure stops the run, and every failure or warning appears as its own finding on the allocation run report. Ready-made helpers cover common questions such as whether exchange rates are present for the period, whether required custom fields are filled in, and whether unit settings exist. Unlocking a run now also unlocks any other run that overlaps it.

### Faster allocation runs for funds with a long history
Funds with a long history spent most of every allocation run copying their entire ledger just to add up Since Inception totals. A fund can now be switched to incremental allocation, where each run stores its Since Inception total and the next run carries it forward, so only the current financial year needs to be copied. The figures are the same; the run is much faster. Funds that are not switched on run exactly as before.

### Switch a fund to incremental allocation from the formulas page
Support staff can make the switch from the fund's Allocation Formulas page under a new Actions menu, which replaces the old Enable All button. The Incremental allocation page shows the fund's status, a checklist of recommended steps marked Done or Next, and a full history of every switch-on, switch-off and recompute. Every change starts as a preview that runs in the background and lists each formula change, anything that blocks the switch, and the recomputed starting values. Apply is offered only on a clean preview, refuses to run while an allocation run is in progress, and writes nothing if anything has changed since the preview.

### Suggested run checks, ready to add in one click
The same Actions menu offers Suggest run checks, which reads the fund's enabled formulas and proposes pre-run and post-run checks with the evidence behind each suggestion. Every suggestion is test-run against the fund's last successful allocation so you can see whether it would pass today. Add the ones you want, or download them as a spreadsheet to review and import later.

### FAQ Manager: keep user guide answers current without a release
Support users can now add, edit and publish FAQs for any user guide directly in the app, so a wrong or missing answer no longer waits for a code change. Published FAQs appear on the guide pages and are used by the Customer Support chatbot, whose guide search now understands synonyms you define and records the questions it could not answer so you can fill the gaps. FAQs can be exported to and imported from a spreadsheet for bulk editing.

### Deal Update Agent handles real-world email more gracefully
Out-of-office replies, bounces and other automatic messages are now dropped silently instead of being filed. Signatures and quoted reply chains are stripped before the agent reads the email, attachments on task emails are saved as documents on the task, and a name mentioned in the email body ("Neil to follow up", "@Priya") is matched to a deal team member and set as the assignee. When the subject line and body name different investors, the email is held for manual review with a Conflicting badge and a reply explaining why. The review form has been reworked with a clearer two-row layout, editable due date and assignee, and a return to the deal once the last email is resolved.

### Portfolio investment report emails no longer borrow another template
The emailed Portfolio Investment Report used the same generic "send document" email as every other shared document, so an entity's custom Statement of Account template could hijack its subject and body, or block it from sending at all. The report now has its own email, which you can customise separately under Custom Notifications.

## Improvements

### Advisors get document and KYC emails wherever they are switched in
An investor advisor who happened to be switched into a different client entity at send time was skipped as a recipient, and the document reported "No users to send the document" even though the advisor could see it on their own records. Recipients are now judged by the advisor's home access, so the email goes out regardless of where they are currently switched in. The "who gets notified" preview on the fund uses the same rule, and an advisor who is denied a page while switched in is told to switch back.

### AI Portfolio Reports link in the Stakeholders Actions menu
Entities with the portfolio report agent enabled now have a direct link to AI Portfolio Reports from the Actions dropdown on the Stakeholders page.

### "Create with Fees" is now "Replicate Distribution"
The action on capital distributions has been renamed to say what it does, and the leftover Clone option has been removed from the distribution page.

### Choose the portfolio company when creating an instrument
The New Investment Instrument form now has a "For" field. Opened from a portfolio company's own Instruments tab, it shows that company and cannot be changed; opened from the entity-wide instruments list, it lets you pick any portfolio company.

### Imports match custom field columns by their on-screen label
Imports that use a Form Tag now match a column to a custom field by the label shown on screen and in the upload template, even when the stored label is blank or the name uses hyphens or underscores. A custom field saved without a label now gets the same label it displays, so the template and the form always agree.

### Daily maintenance jobs run overnight in each region's local time
Scheduled background jobs such as workflow reminders, task generation, user sync and database clean-up were anchored to one UTC time that landed mid-morning in India. They now run in a staggered off-peak window in each region's own time zone, so they no longer compete with daytime use.

### Blazer reports link removed from the sidebar
The unused Blazer reports link has been removed from the sidebar.

### More reliable background processing after deployments
Background job workers are now started and supervised by a single mechanism, with an automatic alert if a worker stalls or if a deployment leaves a duplicate worker running. Previously a duplicate could sit idle after a deploy while monitoring still showed everything healthy.

## What to Do

| If you use...   | Action                              |
|------------------|-------------------------------------|
| Allocation runs | No action needed. To add checks, create a fund formula with rule type PreRunCheck or PostRunCheck, or use Actions → Suggest run checks on the Allocation Formulas page. |
| Incremental allocation | Support only. Open the fund's Allocation Formulas page → Actions → Incremental allocation, follow the recommended steps, and preview before you apply. |
| User guide FAQs | Support only. Open FAQ Manager to add or correct answers; published FAQs appear on guide pages and in the chatbot straight away. |
| Deal Update Agent | No action needed. Check the warehouse for emails flagged Conflicting and resolve them from the reworked form. |
| Portfolio investment report emails | If you want a custom template for this email, add a Custom Notification for the new "send portfolio investment report" method. Existing "send document" templates no longer apply to it. |
| Capital distributions | No action needed. Look for Replicate Distribution where Create with Fees used to be. |
| Investor advisors | No action needed. Advisors now receive document and KYC emails for their own records wherever they are switched in. |
