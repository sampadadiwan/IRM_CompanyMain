# Release Notes — V9.2.88
**Released: 21 August 2026**

---

## What's New

### Warning before you accidentally record the same sale twice

If you enter a sale for a portfolio investment that matches one you already recorded — same date, quantity and amount — you will now be warned before it saves. To go ahead and record it as a genuinely separate transaction, give it its own Reference ID. This closes a gap where an accidental duplicate could quietly throw off the realized gain shown for that investment.

### Tracking currency can only be changed by your CapHive team

A fund's tracking currency is locked once the fund has transactions, since changing it means safely reprocessing the fund's financial history. Previously this lock could be bypassed with a special link; now only your CapHive support team can make the change, and everyone else sees the field as read-only, as intended.

### Suggested tags when adding a user

The Tags field on a user's profile now suggests the tag names CapHive looks for when deciding who to notify (for example, KPI submission alerts). Pick from the suggestions to make sure the right people are included — you can still type any other tag your team uses.

---

## Improvements

### More reliable realized gain calculations on concurrent sales

Fixed a rare timing issue where two sales entered for the same investment at almost the same moment could both draw from the same earlier purchase, producing an incorrect realized gain for one of them.

### New Gemini model available for AI features

Gemini 3.7 Flash has been added to the list of AI models your team can choose from when configuring AI-powered features.

---

## What to Do

| If you use...                     | Action                                                                 |
|------------------------------------|--------------------------------------------------------------------------|
| Recording portfolio sales          | No action needed. If you see a duplicate warning, give the new sale a distinct Reference ID to confirm it's separate. |
| Fund tracking currency             | No action needed. Contact your CapHive team if a fund's tracking currency needs correcting. |
| Adding or editing users            | Use the suggested tags when you want a user included in KPI or system notifications. |
| AI-powered features                | No action needed. Gemini 3.7 Flash is available if your team wants to select it. |
