# Release Notes — V9.2.91
**Released: 30 August 2026**

---

## What's New

### Redesigned Audit Trail — a timeline and a field-by-field history
The audit trail (both the full history page and the version shown on individual records) has been redesigned into one consistent view. It now has a searchable Timeline of who changed or deleted what and when, plus a Field History table that lets you pivot and see exactly how one field's value moved over time. Deleted records now show a direct "Audit Trail" link, and a one-click Restore button appears right on the deletion event.

### Capital calls are now set up through a guided wizard
Creating or editing a capital call is now a step-by-step wizard — call basis and amounts, fees and notifications, and the rest — instead of one long form. Fee rows use the full width of the card, on/off settings are proper toggle switches, and info icons explain each field as you go. If you prefer the old single-page layout, a Classic Form toggle at the top switches back to it at any time.

### Build a report by answering questions, step by step
The report builder has a new guided front door: pick what the report is about, then work through columns, related data, totals, filters, sorting and a final review. Each step explains what it does and shows your report taking shape, and you can jump back to any earlier step. It produces exactly the same report as the advanced builder, so nothing you have already built changes.

### Notification setup wizard, with a preview of what gets sent
Custom notifications are now composed step by step, ending on a Review & Save summary that shows the finished subject line, email body and WhatsApp text exactly as they will go out. The notification's detail page also shows this preview, so you can check the wording of an existing notification without opening it for editing. A Classic Form toggle is available here too.

### KPI submissions move to a guided, step-by-step wizard
Submitting a KPI report is now a multi-step wizard instead of one long form, with Back/Next navigation so you can review earlier steps before submitting. The workbook-check step now shows a single, de-duplicated "Required KPIs" checklist with found/missing badges, and every warning must be individually acknowledged (or "Acknowledge all") before Submit Report unlocks — so a warning can no longer be scrolled past unnoticed.

### Send KYC reminders after seeing exactly who gets one
The Send KYC Reminders button on the KYC list now opens a confirmation popup that spells out what will happen: how many investors will be emailed, who is included (unverified KYCs that aren't yet completed), and what the email contains. Nothing is sent until you confirm.

### Investing Entity name shown alongside investor name
Capital remittances, remittance payments, distribution payments, and account entries now show the linked KYC record's registered name — labeled "Investing Entity" — next to the investor name, both on screen and in xlsx exports. Records without a completed KYC continue to show the investor name as before.

### Clone a capital distribution, including into another fund
Setting up a complex distribution with multiple fee rows no longer means rebuilding it from scratch each time. Clone starts a new distribution pre-filled with the same setup and fees, and you can now choose which fund the clone lands in; Create With Fees starts a blank distribution with just the fee rows carried over. Both are available from the distribution's Actions menu.

### Confirmation prompt when editing a call or distribution date
Changing a capital call or distribution date now warns you first that the change will cascade to every linked remittance or payment date, and asks you to confirm before saving.

### Easier two-factor setup with a zoomable QR code
When setting up an authenticator app, the QR code can now be clicked to open it large and centred, making it far easier to scan on a small or high-resolution screen. The setup screens and their help links have been tidied up so the steps read in order.

### New card styles for the fund manager landing page
The Funds list and the summary and shortcut panels above it on the fund manager landing page can now be shown in any of five card styles — from the classic layout through compact ledger rows, tile grids, a dense stat strip, and chart-forward cards with a capital donut. Your administrator picks the style, and all three panels can be set to match.

### Extra CC recipients on document and commitment emails
Notifications for documents attached to a capital commitment now also go to that commitment's configured CC addresses, alongside the primary recipient.

### Conditional visibility for investor notice items
Individual items inside an investor notice can now carry a criteria expression, so a given item only shows to investors it actually applies to rather than appearing on every notice using that template.

## Improvements

### Refreshed look for the user guides
The in-app user guides and the publicly shared guides now use one consistent layout, with clearer titles and easier navigation between guides. A new walkthrough covering report creation has been added, and demo reports are now tagged so they are easy to find.

### Fiscal year default now matches your region
When a fund or portfolio company hasn't set an explicit fiscal year start month, CapHive now defaults it based on where your instance is deployed (January for the US, April elsewhere) instead of always assuming April.

### Quarterly KPI column headers with extra spacing now import correctly
Column headers like "Q1 FY 25" (with a space before the year) were being misread as monthly data and filed under the wrong period. These now import correctly as quarterly figures, regardless of spacing.

### More data available when building reports
Reports can now pull in more related information for commitments, distributions and remittances without extra setup. Totals across related records and sorting on grouped reports have also been corrected.

### Account entry investor names stay accurate
Renaming an investor now resyncs the investor name already stored on that investor's account entries, and entries moved to a different parent record no longer keep showing the old one — so historical entries don't display a stale name.

### Contact detail changes now reach investor access records
Updating a user's email or phone number now also updates the investor access records linked to them, so you no longer have to correct the same detail in two places.

### Removed a KPI import checkbox that did nothing
The "update existing KPIs" checkbox on the KPI import form had no effect on how the import ran, so it has been removed to avoid confusion.

### Cleaner Documents actions menu
The Documents index actions menu is reordered for a clearer flow (New Document, New Folder, Bulk Upload, Filter Documents, Download), and the "Generate Report" link has been removed — it only ever worked for folders with a report template configured and otherwise dead-ended with an error.

### More accurate remittance approval message
The remittance approval confirmation now only mentions an email being sent when the call is actually configured to send one, and adds a direct link back to the call.

### Cleaner document and card layouts
Removed a duplicated "Created" date row on the document details page, and improved the legibility and spacing of the quick-link step cards on the setup/wizard pages. The setup wizard and funds pages also gained back navigation and clearer multi-entity structure details.

### Signing in after a session timeout now works first time
If your session expired while you were mid-page, returning to the login or two-factor screen sometimes showed a stale or blank page, or lost the message explaining why you were signed out. The sign-in pages now reload cleanly and keep that message.

### Clearer name for fund adhoc notifications
The Fund's adhoc notification is now labelled "Adhoc Fund Notification", so it is easy to tell apart from the commitment-level adhoc notification when choosing which one to configure.

### Refreshed mobile menu on the CapHive website
The public website's navigation menu has been reworked so it opens and reads correctly on phones across every page.

### Steadier deploys and background job processing
Deploys now reliably stop the old background job worker and confirm the new one has taken over, so jobs can no longer be picked up by a stale process. Background job failures are also reported in full rather than being quietly swallowed, which means genuine errors surface instead of disappearing.

### Disaster recovery drills now produce an auditable record
Every disaster recovery drill now generates a dated, auditor-facing report of what was restored, how long it took and how it was verified — useful evidence for investor due diligence and audit requests. Several issues found during live drills have been fixed along the way.

|-----------------|----------|

| Reports | Try the guided wizard for your next new report. Existing reports and the advanced builder are unchanged. |
| Custom notifications | Check the Review & Save step before saving — it shows exactly what recipients will receive. |

| Capital distributions | Try Clone or Create With Fees from a distribution's Actions menu, and pick a target fund if you're cloning into a different one. |
| Capital call / distribution dates | Review the cascade warning carefully before confirming a date change — it updates every linked remittance or payment date. |
| Two-factor authentication | No action needed. Click the QR code to enlarge it if it's hard to scan. |
| The fund manager landing page | No action needed. Ask your administrator if you'd like a different card style. |
| Document notifications on commitments | No action needed. CC addresses already configured on a commitment will now receive these emails too. |
| Investor notices | Set a criteria expression on a notice item if you want it to show only to a subset of investors. |
| KPI imports | No action needed. The "update existing KPIs" checkbox is gone; imports behave exactly as before. |
