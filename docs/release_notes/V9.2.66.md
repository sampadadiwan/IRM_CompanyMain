# Release Notes — V9.2.66
**Released: 28 June 2026**

---

## What's New

### Two-Factor Authentication — choose SMS or WhatsApp for your login code

You can now select how you receive your two-factor authentication code when logging in. In addition to SMS, you can choose to receive it via WhatsApp. The confirmation screen shows your partially masked phone number so you can verify the right number is on file before requesting the code.

### Live Batch Progress — see real-time status when running bulk agent tasks

When a support agent processes multiple records in a batch, a progress panel now updates live as each item is handled. You can see how many have been completed, how many are remaining, and any errors, without having to refresh the page.

### Account Entries Period Report — summarise entries across a date range

A new report is available for account entries that lets you pull a summary across a specific period. This makes it easier to review activity within a given month or quarter without having to export and filter manually.

---

## Improvements

### US-formatted dates and times are now displayed correctly throughout the app

Date and time values across the platform now respect the US locale format (MM/DD/YYYY) for users on US-configured accounts, eliminating confusion when reading dates that previously appeared in a different order.

### Admins can now view the full investor list within a deal

Administrators can now access the investors index page for a deal directly, giving them a complete view of all participating investors without needing to navigate via individual investor profiles.

### Password reset is now available via an emailed link

If you forget your password, you can now request a reset link sent to your registered email address. Following the link takes you to a page where you can set and confirm a new password.

### Preview adhoc notifications before sending to investors

When drafting an adhoc notification for a capital commitment, you can now preview how it will appear before sending, reducing the chance of formatting errors reaching investors.

### CS Agent escalation detail is now visible and flows correctly

When a conversation is escalated by the CS Agent, the escalation reason and detail are now shown clearly in the escalated thread. The handoff logic has also been corrected so it triggers at the right point in the conversation.

### Reports can now be scheduled using a consistent enabled/disabled setting

The scheduling system for reports has been unified so that all scheduled reports use the same "enabled" toggle. Previously, different parts of the app used different flags, which could cause confusion about whether a scheduled report would actually run.

### Remittances are now sorted by payment date by default

The remittances list now sorts by payment date automatically, making it easier to find the most recent payments without manually reordering the table.

### Notes on records are now only shown when they contain content

Fields and panels that display notes will no longer appear empty when no note has been added, keeping the layout clean and reducing visual clutter.
