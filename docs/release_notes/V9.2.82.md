# Release Notes — V9.2.82
**Released: 4 August 2026**

---

## What's New

### Portfolio Company Dashboard — reporting compliance in one place
The Portfolio Company Agent now has its own dashboard where you can see, at a glance, how many companies are up to date on KPIs, documents and valuations, and which ones are overdue. Search or filter by status, open any company to see exactly what's missing, and send reminders straight from the page. The old "Completed" and "Failed" links have been replaced by this single Dashboard view.

### Portfolio checks now look at the last completed reporting period
Compliance checks used to run against the period still in progress, which flagged companies for reports that weren't due yet. They now check the most recently finished period — for example, the quarter ending 30 June — and only during the window you choose, by default starting 15 days after the period ends and stopping after 60 days. You can also pick a specific period from the dashboard and run a check on demand.

### One reminder email covering KPIs, documents and valuations
Reminders previously only chased missing KPIs. A portfolio company now receives a single email listing everything that's outstanding for the period — KPIs, required documents and valuations — instead of separate nudges or none at all. Companies still get at most one reminder a day.

### Agents now warn you when they aren't set up properly
Support agents used to run and report success even when key settings were missing, so you'd get an empty or misleading result with no explanation. Each agent's page now shows a warning listing exactly what's wrong — an empty fund list, a blank recipient list, a missing skill file, a setting that was never turned on — before you waste a run on it. Each agent's user guide now includes a matching setup checklist.

### Deals list — search, quick actions and a side panel in the grid
The deals list view now has a search box, and every row has a menu for View, Edit, Add Note and Add Task. Picking one opens a side panel on the right at the relevant tab, so you can log a note or create a task without leaving the list and losing your place.

### Choose which summary cards appear above your deals list
When creating or editing a deal, you can now choose which summary cards appear above its investor list, and rename them to suit your team. Options include Total Target, Committed (Active), Conversion Rate, Stagnant Leads, Total Deal Amount, Primary Amount, Secondary Amount, Completed % and Number of Deal Investors. Existing deals keep the previous four cards until you change them.

### Last Interaction date shows which investors have gone quiet
Deal investors now carry a Last Interaction date, taken from the date on your latest note or the date a task was completed — whichever is more recent. It appears as a column in the deals grid, on the deal investor page and in the Excel export, and the grid now sorts by it so the investors you haven't touched in a while surface where you'll see them.

## Improvements

### Send Reminders now confirms what it did
Sending reminders from the Portfolio Company Dashboard gave no feedback at all. You now get a clear message telling you whether reminders went out, were skipped because they'd already been sent today, or weren't needed because nothing was overdue. Both Send Reminders buttons also show when reminders last went out and ask for confirmation first.

### The deals side panel closes properly when you navigate away
The investor side panel could stay on screen, or leave a grey overlay behind, after you moved to another page — including when using "All Documents". It now closes cleanly on navigation and when you click outside it, and stacked tooltips and stray page padding have been tidied up.

### Notes and tasks keep deal investors in the right order
Adding a note or completing a task now updates the investor's Last Interaction date, including when steps are completed out of sequence, so the deals list reorders to match. Notes dated in the past no longer push an investor to the top — the date you record is what counts, not when you typed it.

### Fee recomputes report their errors instead of failing
When recomputing fees for distribution payments hit a problem on any payment, the job itself broke down instead of reporting what went wrong. Errors are now collected and emailed as intended, and the job runs cleanly when it's triggered automatically rather than by a person.

### Faster detection of background processing problems
Background job processing is now monitored more closely, including memory use per job type and alerts when processing stops entirely. Operational alerts now link to the right regional dashboard and carry a short summary, so problems are spotted and traced sooner.

|--------------------------------------|-----------------------------------------------------------------------------------------------------|
| Portfolio Company Agent              | Open the new Dashboard link. Check the start/stop day settings and that reminders are set to Yes.    |
