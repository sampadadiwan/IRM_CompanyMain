# Release Notes — V9.2.93
**Released: 06 September 2026**

---

## What's New

### Fund list now shows Committed, Collected and Distributed totals
The funds list has three new columns so you can see committed, collected, and distributed amounts for every fund at a glance, without opening each one. Quick "Dashboard" and "Sign In Report" links have also been added to each fund row for faster access to those pages.

### Filter account entry reports by entry type or allocation run
The account entry report's filter form now lets you narrow results by entry type, in addition to the existing filters. Clicking through from a specific allocation run now opens the report already scoped to that run's entries.

### A new check warns about allocation formulas that can never produce entries
Fund formulas of the "Cumulate" type do nothing if "roll up" is turned off — that combination has always silently produced zero entries. A new validation warning now flags this setup when saving the formula, so the problem is caught immediately instead of discovered later in an empty report.

---

## Improvements

### Allocation run check notifications now link straight to the check
The notification you get after an allocation run finishes now includes a "Check This Allocation Run" link, so you can kick off the Pass/Warn/Fail report directly from the notification instead of navigating there manually.

### Fewer false "Fail" results on allocation run checks
The allocation run checker's amount comparison has been loosened slightly to absorb tiny rounding differences from percentage and FX-rate calculations. Differences too small to ever show up in a displayed amount no longer cause a check to fail.

### Allocation run checks can no longer be triggered twice at once
Clicking "Check" or "Check Again" while a check is already running for that allocation run now just takes you to the in-progress result instead of queuing a second, competing check.

### Smoother navigation from allocation run reports
Links to account entries and fund pages from within an allocation run report now reliably open the full page, instead of occasionally failing to navigate.

### More reliable tooltips on data tables
Tooltips on buttons inside collapsed table columns now consistently appear once that column is expanded, instead of sometimes failing to show up.

### Quick way back to the dashboard from a user's profile
The user profile page now has a "Back to Dashboard" button.
