# Release Notes — V9.2.67
**Released: 30 June 2026**

---

## What's New

### Date fields now have a calendar picker — type or click to pick a date
Date fields across the app now show your date in the correct local format and include a calendar icon you can click to pick a date instead of typing it. Whichever way you enter a date, it's saved correctly behind the scenes.

---

## Improvements

### Generated Word and PDF documents keep their original fonts and spacing
Documents generated from templates (such as agreements and notices) now consistently preserve the intended fonts, spacing, and indentation when converted to PDF, avoiding occasional mismatched fonts or shifted layouts.

### List numbering in generated documents no longer skips or duplicates
Numbered lists and sub-sections in generated documents (e.g. "2.1", "2.2") now number correctly when converted to PDF, fixing cases where an extra or missing number could appear.

### Document generation is more resilient to occasional save errors
If a document fails an internal validation check while being saved, the system now falls back to saving it anyway instead of failing the whole generation, so you're less likely to see a generation error.

### Support staff can now access a company's deals when assisting you
Support users can now view a company's deals and the associated investor list when helping troubleshoot an issue, reducing back-and-forth needed to resolve support requests.

---
