# Release Notes — V9.2.72
**Released: 6 July 2026**

---

## What's New

### Set a default notification for all your calls or distributions, fund-wide
You can now set up a custom call-notice/reminder/payment-confirmation template, or a custom distribution payment template, once at the fund level instead of repeating it on every call or distribution. Open the fund, go to its **Notifications** tab, and choose **New Call Notification** or **New Distribution Notification** from the **New Notification** menu. That template is then used automatically by any call or distribution in the fund that doesn't already have its own override — you only need to set up a call- or distribution-specific one when you want something different for that particular record.

---

## Improvements

### Clearer notification setup, with a heads-up before you override a fund default
The **New Notification** menu on a fund, a specific call, and a specific distribution now only offers the options that make sense in that context, each labeled clearly with a short description of what it's for. If you create a call- or distribution-specific template for an email that already has a fund-wide default, you'll now see a warning before saving, so you know you're about to override the fund's default just for that one record. The notification form's title also now states plainly what the template is for (e.g. "Call Notification" vs. "Distribution Notification").

### Notification emails now link straight back to the record they're about
Turning on the **Show Details Link** option on a custom notification now reliably adds a "View Details" button to the email, taking the recipient straight to the related capital call, distribution, or KYC record.

### Password-protected attachments are handled more reliably
Documents attached to a custom notification and protected with a password now apply correctly even when the password contains special characters, and the email is no longer sent out if password protection fails for any reason.

### Advisors can now be granted the Approver role
When giving an investor advisor access to switch into your fund, you can now assign them the Approver role, alongside the existing role options.

### Distribution fees no longer require a matching account entry name
Setting up a distribution fee that pulls from account entries no longer requires the fee name to exactly match an account entry name — you can now filter by type alone when that's all you need.

### Copying a distribution fee row to all others now copies its dates too
Using "copy to all" on a distribution fee row now correctly carries over its start and end dates along with the other fields.

### Income and Face Value for Redemption fields now accept decimal amounts
These two fields on a distribution now accept decimal values instead of whole numbers only, and lock once the distribution has been created so they can't be changed afterward.

### Distribution detail page now shows custom fields
The distribution detail page includes a new "Other Details" section showing any custom fields configured for distributions.

### Portfolio and Scenario Investment forms handle the instrument field more smoothly
Editing an existing portfolio or scenario investment now immediately loads the fields related to its instrument instead of leaving them blank until you reselect it, and choosing a portfolio company no longer overwrites an instrument you've already picked.

### Adding or removing a portfolio investment on a distribution updates totals correctly
Removing a portfolio investment from a distribution's selection list now updates the Income and Face Value for Redemption totals, matching what already happened when adding one.
