# Release Notes — V9.2.55

**Released: 8 June 2026**

---

## Improvements

### Hurdle CSV — Now filed under the correct commitment

The hurdle computation CSV export is now attached directly to its capital commitment record. Previously the file was saved without a proper owner link, so it could not be found from the commitment's document list. You will now see the hurdle CSV appear under the commitment's documents as expected.

### Allocation Formulas — Clearer errors when a formula divides by zero

If a formula produces an invalid result such as infinity or "not a number" (caused by a divide-by-zero condition), the allocation run now immediately stops and surfaces a clear message identifying the formula at fault. Previously this silent value was written to the database, causing a cryptic failure later in the process. You will see the error in the run's status without having to investigate further.

### Allocation Run Failures — More detail when data loading fails

When the underlying data load for an allocation run fails, the error message now includes the exit code and the relevant output from the load script. If a final data-transfer step fails, your team will also receive an in-app notification rather than seeing the run silently stall. Both changes make it faster to diagnose and resolve allocation failures.
