# Release Notes — V9.2.86
**Released: 15 August 2026**

---

## What's New

### Portfolio Scoring Dashboard — your whole portfolio at a glance

Scoring results now have a dashboard of their own. See the average score across your portfolio, how companies are spread across grades, and which ones moved up or down since the last run. Filter by tier, sector, or status and the whole view follows, including a headline summary of how much value needs attention. Insights below the table call out the weak spots that show up most often and how scores are trending over time.

### File investor emails straight from Outlook or Gmail

You can now file an email into CapHive without leaving your inbox. The add-in suggests the right investor based on who sent the email, files any attachments with it, and tells you if the email has already been filed so nothing is recorded twice. Everything you file is visible to your whole team on the investor's page. Ask your administrator to install it — it works in Outlook on the web, the Outlook desktop apps for Windows and Mac, and Gmail.

### Portfolio Company reminders — choose exactly who gets chased

You now control who receives KPI reminders and which companies are included. Pick the companies to validate by tag, sector, or name from searchable dropdowns, set the contacts each reminder should go to, and mark individual companies to be skipped entirely. You can also run a validation without sending any reminders, and send reminders to a hand-picked set of companies on demand. After each run you get a summary email showing which companies are up to date, which have issues, and what is missing.

---

## Improvements

### Documents with extra spaces in their names now attach correctly

A document whose name contained a doubled space — usually created automatically from a template — looked completely normal on screen but would not attach to notifications that asked for it by name. Document names are now tidied up when saved, existing names have been corrected, and the names you type into a notification's attachment list are matched the same way.

### Deal step tasks are no longer created twice

Importing investors into a deal could generate a duplicate set of step tasks. Tasks are now created once per investor, so your deal checklist reflects the real work outstanding.

### AML Reports page no longer errors for some users

Opening AML Reports from an investor's KYC record could fail with an error for investor users, group company parents, and support staff. The page now loads correctly for everyone who is allowed to see it.
