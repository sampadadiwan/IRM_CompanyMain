# Release Notes — V9.2.48
**Released: 27 May 2026**

---

## What's New

### Note Summarizer — AI Summaries of Investor Notes
A new AI agent reads your investor meeting notes and produces a concise written summary for each investor. Summaries appear in a dedicated tab on the investor card and in a new dashboard widget, so your team can quickly review the key themes and action items without reading every raw note entry. The agent can be configured per fund and run on demand.

### Inline Editing — Edit Summaries and Scorecards Without Leaving the Page
Note summaries and scorecard entries can now be edited directly on the investor card — double-click any summary or score field to enter edit mode, make your change, and save without opening a separate form. Changes are reflected immediately on the page.

### KYC Send Workflow — Magic Links and Status Tracking
Fund admins can now send investors a personalised KYC form link directly from the KYC index. The investor receives an email with a secure one-time link that opens their KYC form without requiring a login. The system tracks whether the link was sent, when the investor started filling in the form, and whether they submitted it, giving your team full visibility over outstanding KYC requests from a single view. A **Pending KYC Requests** button on the index page filters to investors who have been sent a link but have not yet submitted.

### Document-First KYC — Upload an ID and Let AI Pre-Fill the Form
When an investor opens their KYC link, they can now upload their identity document first. An AI extraction step reads the document and pre-populates the KYC fields in a single pass, reducing the manual data entry required before submission. Admins can review and correct the extracted values before the record is finalised.

### Distribution Fees — Copy Values Across Entries and Track Cumulative Amounts
The distribution fee section now supports a **Copy to All** button that pushes the values from one fee entry to all others in a single click — useful when the same fee applies across multiple account entries. You can also expand or collapse all account entries together. Two new fields — cumulative amount and entry type — give you finer control over how fees are categorised and rolled up.

### Filter Lists by Your Own Custom Fields
Any custom field marked as filterable by your admin now appears as a filter option in the search panel across capital commitments, KYC records, account entries, portfolio investments, and valuations. Text fields support keyword search, number and date fields support range filters, and dropdown fields support exact-match selection — all alongside the standard built-in filters.

### KPI Notifications — Tag-Filtered Emails and Entity Name in Subject
Fund employees can now be tagged per investor relationship so that KPI submission and reminder emails only go to the people responsible for that relationship, not everyone on the fund team. The sending entity's name is also now included in the email subject, making it easier to identify which fund or company the notification relates to at a glance.

### Hurdle Computation — Export Results to CSV
Hurdle calculations can now be exported to a CSV file directly from the computation results. This makes it straightforward to share or further analyse the hurdle data outside the platform.

### PDF Documents — Accessibility Support
Documents generated by the platform — including KYC forms, capital call notices, distribution notices, and SOAs — are now produced with accessibility metadata embedded. Screen readers and other assistive tools can navigate these PDFs correctly.

## Improvements

### Custom Form Fields — Checkboxes Now Visible on the Detail View
Checkbox fields defined in custom forms are now displayed correctly when viewing a completed form record. Previously, checkbox values were not rendered on the show page.

### KYC Document Upload — More Reliable Email Notifications
Email notification checks during the document upload step have been tightened so that notifications fire correctly in edge cases where they were previously skipped.

### KPI and KYC Reminder Modals — Refreshed Visual Style
The reminder modals used for KPI report reminders and KYC update requests have been updated to match the current modal design across the platform. Behaviour is unchanged.

### AI Support Agents — Latest Report Always Shown
The KYC onboarding agent and portfolio company agent now track which report run is the most recent. Investor and portfolio company pages show only the latest report by default, with a compact grid layout for quick scanning.

### AI Support Agent Menus — Unavailable Options Are Clearly Marked
Agent run options that are not enabled for your fund are now shown in a greyed-out state rather than being hidden entirely. This makes it clear which agents are available and which need to be configured before use.

### Gross Portfolio IRR — Calculation Fix
A reference error in the gross portfolio IRR calculation has been corrected. Funds using this metric should see accurate results for scenarios where the previous calculation produced incorrect figures.

### Platform Performance — Faster Page Loads
A broad set of query optimisations has been applied across portfolio investments, capital commitments, deal management, KPI reports, and secondary sales. Pages that previously triggered redundant database queries now load noticeably faster, particularly for funds with large datasets.

### Security — User Lookups Restricted to Active Accounts
Authentication and account lookup queries now only match active accounts. Inactive or suspended accounts are excluded from consideration, reducing the attack surface for user enumeration.
