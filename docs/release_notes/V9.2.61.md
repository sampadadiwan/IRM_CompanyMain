# Release Notes — V9.2.61

**Released: 20 June 2026**

---

## What's New

### Workflow Templates — structured approvals for your folders

You can now create reusable workflow templates that define a sequence of steps, each assigned to specific team members. Once a template is set up, you can launch a workflow against any folder — the system activates each step in order, emails the assigned person with a secure link, and waits for their response before moving on. Reviewers can approve, reject, or request changes directly from the email without logging in. The full history of who responded and when is captured for audit purposes.

### Email reminders keep workflows moving

If an assigned reviewer hasn't responded within the expected window, the system automatically sends them a reminder. Your team no longer needs to chase people manually — pending actors get nudged on schedule so workflows don't stall.

### Categorise your AI support agents

Support agents can now be assigned a category (for example, "Investor Relations" or "Compliance"). The support agent index page groups agents by category and includes a search filter so your team can find the right agent quickly as your library grows.

---

## Improvements

### New users can access the app immediately without email confirmation

Previously, newly invited users had to confirm their email address before they could log in. That confirmation step has been removed — users now land straight in the app after accepting an invitation, with no extra step required.

### Tighter access control on workflow features

Workflow template creation and management is now gated by entity-level permissions, so only the right roles can set up or modify templates and launch workflows.

---

## What to Do

| If you use...            | Action                                                                                          |
| ------------------------ | ----------------------------------------------------------------------------------------------- |
| Folder approvals         | No action needed. Open any folder and use the new Workflow tab to launch a workflow template.   |
