# Release Notes — V9.2.81
**Released: 31 July 2026**

---

## What's New

### KPI workbook uploads — smarter parent-child matching and custom tags
KPI uploads now correctly match parent and child line items even when the same child name appears under different parents, so figures land against the right KPI instead of overwriting each other. Tags in your Excel file (like "IC Case", "Budget Case", or "Forecast") are now shown exactly as you wrote them instead of being relabeled, and Forecast now has its own badge color so it's easy to tell apart from Budget at a glance.

### LP dashboard notices now follow your selected GP
On the investor dashboard, the notices shown to LPs now update to match whichever fund sponsor they've switched to, so you no longer see notices meant for a different fund.

---

## Improvements

### Deal creators can now add deal steps
Fixed an issue where the person who created a deal couldn't add or manage steps on their own deal.

### Primary email is locked once a stakeholder has linked users
To protect stakeholder access from being accidentally broken, you can no longer change a stakeholder's primary email once they have users linked to their account. Remove the linked users first if the email needs to change.

### Clearer errors for bulk portfolio report generation
Bulk portfolio report generation now shows one clear summary of what went wrong instead of multiple confusing messages, and the KPI report preview shows a proper message when there's nothing to preview.

### Stakeholder column no longer required for account entry and payment imports
Imports for account entries, capital distribution payments, and capital remittances now work out investor and folio details automatically, so the "Stakeholder" column is no longer needed. Older files that still include it will continue to work fine.

### Custom fields display more reliably
Checkbox custom fields now show a sensible Yes/No by default even without extra setup, and currency values on custom fields display correctly when no currency is configured.

### Notes show clearer dates
The "On" date on a note now has a short explanation of what it means, and notes now show "On" and "Created At" as their own clearly labeled rows instead of being run together.

### Fund formulas list is easier to work with
The fund formulas list can now be sorted by clicking column headers, and downloading the list now includes the formula's AI-written description.

### Grid tables render correctly on the classic theme
Fixed a display issue where data grids didn't render properly for accounts still using the older, classic theme.

### Clearer message when your session times out
If your session expires while you're on a page, you'll now see a clear message explaining what happened with an option to reload, instead of a broken or blank screen.

### Stronger protection against scanning bots
Added extra defenses against automated bots probing for pages on the site, tuned so that real users sharing an office or VPN network are never mistakenly blocked.
