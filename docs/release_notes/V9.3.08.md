# Release Notes — V9.3.08
**Released: 23 October 2026**

---

## What's New

### KPI Quarter, YTD and Year totals — correct for mixed reporting
Portfolio companies that report some quarters by month and others by quarter now get the right Quarter, YTD and Year figures.

- **Uploads and manual edits are never overwritten.** Only figures CapHive calculated itself are updated or removed when the underlying data changes.
- **Missing months are not treated as zero.** A Quarter is calculated only when all three months are present.
- **Fiscal year start respected.** Totals follow the fiscal year start month of the company, your entity or your region, instead of always January.

### YTD % change — compared with the same month last year
The change shown for a YTD figure now compares it with the YTD from a year earlier, so it reflects growth rather than just the latest month's contribution. If there is no figure from a year earlier, the change shows "-".

### Portfolio report — Actual vs Budget, stake, IRR and MOIC
- **Actual vs Budget.** Every Actual column now has a matching percentage against the approved Budget. It shows "N/A" when the Budget is missing, zero or not yet approved, and picks up a Budget approved later on the next report.
- **Stake and first investment date.** Reports can now show the company's current stake and the date of your first investment in it.
- **IRR and MOIC per fund.** Each fund section can show the company's IRR and MOIC in that fund, as of the report end date.
- **Percentage KPIs format correctly.** Templates can now tell whether a KPI is a money, number or percentage value, and can scale a number by a power of ten (for example, 0.12 shown as 12).

### Approve all KPIs — runs in the background
**Approve all** no longer makes you wait on the page when a company has hundreds of KPIs waiting. Approval runs in the background, and you get a notification when it finishes, including how far it got if something went wrong.

---

## Improvements

### Fund audit trail records only what people changed
Account entries are now audited only when a person adds, edits or deletes one. Changes made by allocation runs, imports and automatic recalculations no longer fill the audit trail with noise.

### View Documents button on folder pages
A new **View Documents** button on a folder page takes you back to the Documents list with the full folder tree, the current folder highlighted and its documents shown.

### Faster capital calls, KPI uploads and imports
Capital call generation, KPI uploads and recalculations, formula and portfolio investment imports, deal step creation and portfolio re-valuation now do less work per record, so large runs finish sooner. Results are unchanged.

### Faster document, approval and report screens
The folder pages, approval lists, distribution payment lists and a few other screens load with fewer lookups.

### Allocation runs no longer fail intermittently
Fixed an occasional "No unique index found for id" error that could stop an allocation run.

## What to Do

| If you use...                  | Action                                                                              |
|--------------------------------|-------------------------------------------------------------------------------------|
| KPI Quarter / YTD / Year       | Run **Recompute Auto-Fill** on affected companies to refresh totals and YTD % change. |
| Portfolio report templates     | Add the new Actual vs Budget, stake, IRR and MOIC fields to your templates if wanted. |
| KPI **Approve all**            | You will be notified when approval finishes; no need to stay on the page.            |
| Everything else                | No action needed.                                                                   |
