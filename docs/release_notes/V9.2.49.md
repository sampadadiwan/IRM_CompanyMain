# Release Notes — V9.2.49
**Released: 28 May 2026**

---

## What's New

### Notification Subscriptions — Receive Only Your Investor Alerts
Team members can now be tagged per investor relationship so that notifications are delivered only to the people responsible for that relationship. Capital call notices, distribution payments, remittance confirmations, investment opportunities, approval responses, and deal activity emails all respect these tags — if you are not tagged for a given investor, you will no longer receive notifications for them. Users with no tag assigned continue to receive all notifications as before.

---

## Improvements

### Access Permissions — Changes Take Effect Immediately
Permission checks are now performed in real time against the database rather than from a cached snapshot stored on your user account. This means that when an admin grants or removes access to a fund, investor, or portfolio company, the change is reflected immediately — no delay, no stale permissions, and no need to log out and back in.

### KYC Document Extraction — More Consistent AI Prompting
The AI extraction step that reads uploaded identity documents during KYC onboarding has been made more reliable. Edge cases where the extraction prompt could produce inconsistent field mappings are now handled correctly.

### Investor Access — Tighter Visibility Controls for Standard Users
Visibility rules for standard (non-admin) users viewing investor records have been tightened to ensure they only see investors they have been explicitly granted access to.

---

## What to Do

| If you use...                          | Action                                                                                                    |
|----------------------------------------|-----------------------------------------------------------------------------------------------------------|
| Capital call and distribution emails   | Ask your admin to assign notification tags to each investor access record so emails go to the right people. |
| Investment opportunity notifications   | Same as above — tag-based routing now applies to investment opportunity emails too.                        |
| Deal activity notifications            | Tag-based routing now applies. Contact your admin to set up tags if needed.                               |
| Access rights management               | No action needed. Permission changes now take effect instantly.                                           |
| KYC document upload                    | No action needed. Extraction improvements apply automatically.                                            |
