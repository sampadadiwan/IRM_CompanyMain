# Release Notes — V9.2.57

**Released: 12 June 2026**

---

## What's New

### Investor Presentation Analyst — AI review of investor documents

A new AI agent can now analyse investor presentation documents and produce a structured report with metrics and flags. When the feature is enabled for a fund, an Analyse button appears on the investor page, and results appear in a dedicated Presentation Reports tab. Scoring and question-based checks can be turned on or off independently to match your review workflow.

### Deal Investor Import — Upload spreadsheets with multiple sheets

The deal investor import now handles workbooks that spread data across more than one sheet. Your team no longer needs to consolidate data into a single sheet before uploading — the importer reads all relevant sheets automatically.

### Deal List — Choose which columns to display

You can now configure which columns appear in the deals grid. A column-picker control lets your team show or hide fields to match how you work, and the selection is saved per deal so it persists between sessions.

---

## Improvements

### Deal Excel Export — Notes and activity data now included

When you export deal investors to Excel, the file now includes deal investor notes and a richer set of activity fields. Column headers have also been restructured so the data is easier to read and import into other tools.

### Deal Investor Fields — Human-readable labels in forms and exports

Custom fields on deal investor records now display the label your team configured rather than the raw field name. If no label has been set, a clean human-readable version of the field name is shown instead.

### KPI Table — Periods now appear in date order

Period columns in the KPI table are now sorted chronologically from left to right. Previously the order could vary depending on how data was loaded.

### Portfolio Report Drafts — Faster PDF processing

PDF extraction for portfolio report drafts has been optimised. Large or complex PDFs are processed more efficiently, reducing the time it takes to generate a draft from uploaded documents.

### Notes — Return to the right page after saving

After creating a note, you are now returned to the page you came from rather than a generic landing page. This avoids the extra navigation step that was previously needed to get back to your work.

### Fund Ratio Popup — Calculations now appear reliably

A timing issue that caused the fund ratio scenario popup to sometimes show a blank result has been fixed. Ratio calculations now load and display correctly every time.

### Report Templates — Updated layout attributes for PPTX and DOCX

Presentation and document templates have been updated with additional layout and style attributes. Exported reports will reflect these changes automatically on the next generation.
