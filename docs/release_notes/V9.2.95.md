# Release Notes — V9.2.95
**Released: 12 September 2026**

---

## What's New

### Shareholder positions and a horizontal cap table
Portfolio companies can now hold shareholder positions alongside your regular investments, uploaded from a spreadsheet the same way other cap table data is imported. Positions go through an approval step, with clear errors when a round's percentages don't add up, and once approved they appear on a new horizontal cap table with ownership charts and per-round grouping.

### Pick exactly which remittances to verify in bulk
The bulk-verify modal for capital calls used to check every unverified remittance at once, including ones with nothing collected yet — with no way to hold any back, even though verifying sends payment notifications. It now lists only remittances that are unverified and have money collected, lets you select specific ones, and still verifies everything eligible if you leave the selection blank.

---

## Improvements

### Two-factor sign-in is simpler and more consistent
Backup codes have been retired in favor of the existing reset flow. Undeliverable SMS and WhatsApp codes now show the same clear message, switching two-factor methods off and back on behaves consistently, and a few edge cases around resetting and re-enrolling have been tightened up.

### AI answers about fund ratios no longer get invented
When no stored ratio (TVPI, DPI, RVPI, IRR, etc.) matches a query, the AI now says plainly that none is available instead of quietly calculating its own from raw calls and distributions.

### Numeric columns line up properly
Numbers in data tables — amounts, quantities, percentages — now use evenly-spaced digits, so values of the same length look the same width instead of the zero-heavy ones appearing wider.

### Fewer clicks lost to a stray dropdown on the distributions page
A dropdown menu on the distributions page could stay open or misbehave after repeated use. It now opens and closes cleanly every time.

### KPI budget and compound views handle their filters correctly
The budget and compound toggles on KPI reports now read their setting correctly in every case, instead of occasionally misreading it as off when it was on.

### Cloning removed from capital distributions
The Clone action has been removed from capital distributions; distributions are created directly instead.

### Tidier investment opportunity previews
The Track Record section no longer shows an empty heading on opportunities that have no track record, and the thesis preview no longer repeats the company name and tags that are already shown elsewhere on the page.

### Smoother instrument creation while adding a portfolio investment
Creating a new investment instrument from the portfolio investment form now carries the portfolio company you already selected, and the "New Instrument" link is hidden until a portfolio company has been chosen.

### Video previews are harder to save from the browser
Right-click and the built-in download control are now disabled on document video previews.

## What to Do

| If you use...   | Action                              |
|------------------|-------------------------------------|
| Portfolio companies | No action needed. Upload a shareholder positions spreadsheet to start using the new import and approval flow, then view the horizontal cap table once positions are approved. |
| Capital call bulk-verify | No action needed. Open the bulk-verify modal to pick specific remittances, or leave the selection blank to verify everything eligible as before. |
| Two-factor sign-in | If you were relying on a saved backup code, use the existing reset flow instead — backup codes are no longer available. |
| Capital distributions | No action needed. Use the standard create flow; Clone is no longer on the page. |
| AI clients connected to CapHive | No action needed. Missing fund ratios now come back as "not available" rather than a computed guess. |
