What the measured time covers

The headline figure is rebuild time, not end-to-end recovery time objective. It is measured from the start of the recovery command to the stack passing verification.

Included
Infrastructure provisioning · configuration rewrite · application deploy to every server · database restore from backups, primary and replica in parallel · replication re-pointing · migration replay · the full verification scorecard above.
Excluded
Incident detection · the human decision to declare a disaster · DNS cutover and its propagation delay. Cutover is deliberately a manual step and is never performed by the recovery sequence.

A true incident-to-service-restored figure is the time above plus those three components. Stated explicitly so the number is not read as more than it is.
