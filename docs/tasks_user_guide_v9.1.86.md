# Tasks Features User Guide (V9.1.86)

With the latest update (V9.1.86), the Tasks module has been enhanced with new visualization tools, recurring tasks, and improved categorization to help you manage your workload more effectively.

## 1. Task Statistics Dashboard
The Tasks index page now features a summary dashboard at the top, providing an at-a-glance view of your task status.

*   **Completed:** Quickly see the total number of tasks finished.
*   **Incomplete:** Track tasks that still require action.
*   **Delayed:** Automatically identifies tasks where the due date has passed but the task remains incomplete.
*   **Due This Week:** Monitors tasks that need to be prioritized within the current week.

Each statistic card is clickable, allowing you to instantly filter the task list to focus on that specific category.

## 2. Category Management
To better organize your work, tasks can now be assigned to specific functional categories. This allows for improved filtering and reporting across different departments.

*   **Standard Categories:** Choose from predefined categories such as **Finance**, **Ops**, **Compliance**, **IR**, or **Other**.
*   **Custom Selection:** If the predefined options don't fit, you can specify a custom category name using the "Other" field in the task form.

## 3. Recurring Tasks
You can now automate the creation of repetitive tasks by setting up recurrence rules.

*   **Frequency:** Set tasks to repeat **Daily**, **Weekly**, **Monthly**, or **Yearly**.
*   **Intervals:** Define how often the task should repeat (e.g., "Every 2 weeks" or "Every 3 months").
*   **End Conditions:** Optionally set an end date for the recurrence to stop automatically.

To make a task recurring, simply check the **"Make Recurring"** box in the task creation or edit form.

## 4. Advanced Filtering for Delayed Tasks
A new **Delayed** scope has been added to the system. You can now specifically search for or filter tasks that are past their due date using the search and filter panel. This helps in identifying bottlenecks and ensuring critical deadlines are not missed.

## 5. Improved Navigation & UI
*   **Statistics Integration:** The statistics cards integrate directly with the existing filtering system, making it easier to pivot between different views (Timeline vs. List).
*   **Rich Text Support:** Task details and responses now support rich text formatting, allowing for clearer communication and documentation.
